# leetcode-java-study

Архив решений задач LeetCode на Java: учусь на них алгоритмам и коллекциям.

## Структура
- `week-1/` — неделя 1: массивы, строки, хеш-таблицы, два указателя, интервалы (15 задач).
- `extra/` — задачи вне плана.
- `1week/` — первые заходы (оставлены как есть).

В каждом файле в шапке: название, уровень, ссылка на задачу, оценка по времени и памяти. Память указана без учёта возвращаемого массива, если не оговорено иное.
